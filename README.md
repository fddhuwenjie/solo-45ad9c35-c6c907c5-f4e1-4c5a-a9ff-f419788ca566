# 间歇式呼吸室分析工作台

浏览器工作台，用于间歇式呼吸测量（intermittent respirometry）的耗氧率分析。
针对氧浓度曲线中夹杂的**开盖换样、探头漂移、搅拌未稳、气泡、传感器断点**
等问题区段，支持交互式选择稳态窗、分段零点漂移修正、线性回归与
温压体积换算，并给出完整的告警、版本管理与导出成果。

**多周期批量分析**：一份记录通常包含多个"冲洗—封闭测量"周期。批量分析页
可按 flush 事件或氧浓度回升阈值自动分段，在总览曲线上拖动各周期起止边界、
锁定已确认周期（规则变化只重算未锁定部分），逐周期给出 MO₂、斜率、R²、
残差、有效点数与告警，按中位数绝对偏差（MAD）识别速率离群并记录
保留/剔除理由，汇总有效周期的均值、标准差与变异系数，版本可撤销，
并导出逐周期 CSV、分段参数 JSON 与含总览图的批次报告。

**时变空白校正**：空白室微生物耗氧随实验进程变化，只扣最近一次空白均值
容易校正过头或不足。"空白序列"页可为多份空白数据填写采集时刻组成
**背景序列**——每个锚点自动取其空白室**已确认批次版本的有效周期均值**
（也可锁定人工指定值），在批量分析中按**最近锚点**或**线性插值**沿时间轴
对齐各样本测量窗，逐周期给出采用的空白速率、来源区间与插值权重。
锚点可停用、可调整时刻；锚点变化只为**受影响样本**自动生成关联新版本，
旧结果仍可查阅。缺少前后锚点、锚点间隔超阈值、区间外推、符号反转时
界面说明原因，需人工确认后才纳入汇总。

## 技术栈

- **服务端**：Python 标准库 `wsgiref` + `sqlite3`（无第三方依赖）
- **前端**：HTML / CSS / 原生 JS（SVG 绘图，无框架）
- **数据**：`data/` 内含带漂移、开盖、断点的合成 CSV

## 运行

```bash
python3 server.py            # 默认 http://127.0.0.1:8000
python3 server.py --port 9000
```

浏览器打开后：

1. **上传 CSV**（或上传 `data/` 下的合成数据），填写数据集名称、样本编号，
   空白室勾选"空白室"。
2. 在曲线图上**拖动**选择稳态窗，避开事件区段（红色虚线为事件标记）。
3. 需要漂移修正时，点"添加校准点"后在曲线上**点击**放置校准点
   （期望值默认为该时刻温压对应的饱和氧浓度，可修改；点击已有点可删除）。
4. 选择空白室、R² 阈值、最少点数，点"运行分析"。
5. 查看斜率、R²、残差图、有效点数与耗氧率 MO₂（mg/h，空白修正前后）。
6. 每次分析形成一个**版本**，"撤销"回退到上一版本。
7. "分组比较"页按样本编号归组，可记录**剔除理由**并恢复。
8. 导出：修正曲线 CSV、窗口参数 JSON、带图实验报告（HTML，内联 SVG）。

## 批量分析（多周期）

"批量分析"页处理整份"冲洗—封闭测量"记录：

1. 选择数据集（空白室同样适用），设置**分段规则**：
   - **按 flush 事件**：以 event 列含关键字（默认 `flush`）的点为冲洗边界；
   - **按氧浓度回升阈值**：自动检测回升（冲洗）区段，测量窗在区段之间——
     终点为下次回升开始前 `周期末预留`，起点为上次回升结束后 `冲洗后跳过`，
     回升点不会并入测量窗。
2. 点"自动分段"生成候选周期；在总览图上**拖动周期两侧竖线**调整边界，
   点 🔒 **锁定**已确认周期（重新分段只补入未锁定区域），
   也可用"添加周期"在图上拖动手动补段。
3. 需要漂移修正时，用"添加校准点"在曲线上点击放置（与单窗一致）。
4. 每周期沿用校准、空白修正与温压体积换算，表中显示 MO₂、斜率、R²、
   有效点数与告警标签；点击色带或表格行查看该周期**残差**。
5. 带任一告警（重叠/过短/跨事件/R² 不足/离群等）的周期默认**不计入**汇总；
   速率离群按 MAD 修正 z 值（|z|>3.5）识别。在表中裁决"保留/剔除"并填写
   理由后，汇总即时更新（均值、标准差、变异系数、中位数）。
6. "保存版本"固化当前分段与裁决（可"撤销"回退）；导出逐周期 CSV、
   分段参数 JSON、含总览图的批次报告。
7. 空白室经批量分析后，其有效周期均值自动作为后续分析的空白速率
   （无批次版本时回退到最近单窗版本）。

## 时变空白校正（背景序列）

"空白序列"页管理背景序列，批量分析页选用后替代静态空白：

1. **建锚点**：每个锚点对应一份空白室数据，填写**采集时刻**（与样本
   时间轴一致）。速率自动取该空白室**最近已确认批次版本的有效周期均值**
   （界面显示来源版本）；填"锁定值"则改为人工指定校正值；异常锚点可
   **停用**（灰叉显示，不参与校正）。
2. **校正方式**：**线性插值**（默认）或**最近锚点**；可设**锚点间隔阈值**，
   超过即告警。预览图显示锚点速率随时间的变化模型。
3. **逐周期对齐**：批量分析在每个测量窗中点取值，表格新增"空白速率 /
   来源区间 / MO₂前"列，总览图下方的时间轴条显示锚点、模型曲线与各
   周期实际采用速率（绿=计入，红=未计入）。
4. **锚点版本**：每次保存使序列 rev+1、变化锚点 rev+1；引用本序列且
   结果发生变化的样本会**自动生成关联新版本**（注明来源版本），
   旧版本仍可查阅；速率未变的样本不产生新版本。空白室**新增已确认批次**
   （或撤销批次）使其有效均值变化时，引用该空白室的未锁定锚点所在序列
   同样自动 rev+1 并重算受影响样本；**锁定锚点不受来源批次变化影响**。
5. **告警与确认**：`BLANK_*` 告警（见下表）与符号反转的周期默认不计入
   汇总，在表中裁决"保留"并填写理由后才纳入。
6. **导出记录**：逐周期 CSV 含 `blank_mode / blank_rate / blank_scaled /
   blank_weight / blank_anchors`（锚点 id、版本、时刻、速率）；参数 JSON
   记录序列 id、rev、方法与间隔阈值；批次报告含背景模型章节
   （锚点表 + 时间轴图）。

## CSV 格式

```csv
time,o2,temp,pressure,volume,event
0,8.4901,22.0,101.3,0.95,
5,8.4898,22.0,101.3,0.95,
660,8.91,22.0,101.3,0.95,lid_open
```

- 必需列：`time`（Unix 秒 / `HH:MM:SS` / ISO 时间戳）、`o2`（mg/L）
- 可选列：`temp`（°C）、`pressure`（kPa）、`volume`（L）、`event`（事件标记）

## 分析流程

1. **分段零点漂移修正**：校准点间线性插值偏移量，端点外取最近端点值，
   从原始曲线扣除。
2. **窗口线性回归**：最小二乘拟合稳态窗内修正曲线，得斜率、截距、R²、残差。
3. **温压体积换算**：浓度按 `(273.15/(273.15+T))·(P/101.325)` 折算到标准状况，
   `MO₂ = -slope·V·3600`（mg/h，耗氧为正）；空白室速率按体积比折算后扣除。

## 告警条件

| 代码 | 含义 |
|---|---|
| `EVENT_IN_WINDOW` | 窗口跨越事件标记（开盖/气泡/断点等） |
| `TOO_FEW_POINTS` | 窗口内有效点数少于下限 |
| `TIME_REVERSED` | 窗口内时间倒序 |
| `WINDOW_REVERSED` | 窗口起止时间倒序（已自动交换） |
| `LOW_R2` | R² 低于阈值 |
| `SIGN_FLIP` | 空白修正后耗氧率符号反转 |
| `CYCLE_OVERLAP` | （批量）与相邻周期时间重叠 |
| `CYCLE_TOO_SHORT` | （批量）测量段短于下限 |
| `RATE_OUTLIER` | （批量）速率离群：MAD 修正 z 值绝对值 > 3.5 |
| `BLANK_NO_ANCHOR` | （时变空白）无可用锚点（均停用或缺已确认批量均值），未做修正 |
| `BLANK_NO_BRACKET` | （时变空白）缺少前后锚点（仅 1 个可用），回退到该锚点 |
| `BLANK_GAP_TOO_LARGE` | （时变空白）锚点间隔/最近锚点距离超过阈值 |
| `BLANK_EXTRAPOLATE` | （时变空白）测量窗超出锚点区间，按最近两锚点线性外推（负值截断为 0） |

## 合成数据（`data/`）

`python3 data/make_synthetic.py` 重新生成：

| 文件 | 包含问题 |
|---|---|
| `fish_A_run1.csv` | 线性漂移、开盖复氧（900–960s）、气泡尖峰（750s）、传感器断点（1300–1360s 卡死） |
| `fish_A_run2.csv` | 两段速率非线性漂移、前 240s 搅拌未稳振荡 |
| `fish_B_run1.csv` | 温和漂移、t=900s 处时间倒序坏点 |
| `fish_C_run1.csv` | 5 个周期，第 4 周期耗氧率异常偏高（MAD 离群演示） |
| `blank_chamber.csv` | 空白室：微生物耗氧 + 漂移 |
| `blank_chamber_late.csv` | 第二份空白室（3600–5400s，速率略高，时变空白演示） |

## API 概览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/upload?name=&sample_id=&is_blank=` | 上传 CSV（body 为文本） |
| GET | `/api/datasets` / `/api/dataset/<id>` | 列表 / 详情（含单窗与批次版本） |
| POST | `/api/analyze` | 运行单窗分析并保存版本 |
| POST | `/api/undo` | 撤销到上一版本 |
| GET | `/api/versions/<id>` | 版本历史 |
| POST | `/api/exclude` | 记录/撤销剔除理由 |
| GET | `/api/groups` | 按样本归组比较 |
| GET | `/api/export/csv/<id>` | 修正曲线 CSV |
| GET | `/api/export/json/<id>` | 窗口参数 JSON |
| GET | `/api/report/<id>` | 带图实验报告 HTML |
| POST | `/api/batch/analyze` | 批量分析：`resegment` 时按 `seg` 规则分段（锁定周期保留），`save` 时保存批次版本；`blank_series_id` 启用时变空白（优先于 `blank_id`） |
| POST | `/api/batch/undo` | 撤销最近批次版本 |
| GET | `/api/batch/versions/<id>` / `/api/batch/version/<vid>` | 批次版本列表（摘要）/ 单版详情 |
| GET | `/api/batch/export/csv/<id>` | 逐周期结果 CSV（含空白速率/来源/权重列） |
| GET | `/api/batch/export/json/<id>` | 分段参数 + 逐周期结果 JSON（含背景模型与锚点版本） |
| GET | `/api/batch/report/<id>` | 含总览图的批次报告 HTML（含背景模型章节） |
| GET | `/api/series` | 背景序列列表（锚点含解析速率）+ 各空白室已确认批量均值 |
| POST | `/api/series/save` | 创建/整体更新背景序列；变化使 rev+1 并为受影响样本自动重算关联新版本 |

数据库文件默认为 `respiro.db`（可用环境变量 `RESPIRO_DB` 覆盖）。
